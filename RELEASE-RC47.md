# RC47 keeps task operations available with a damaged inbox

Swarm pause, resume and stop and privilege-case lookup skip unreadable or malformed inbox records when locating other tasks. A damaged record alone no longer makes the background service start the local router. The worker continues to log invalid inbox files.

Release CI selects the notes that match the tagged release candidate.

The terminal task view refreshes labels that are still mounted when Textual removes task rows.
