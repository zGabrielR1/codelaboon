# RC34 brings Claude.ai browser setup to the web workspace

Open **Connections**, find **Claude.ai (Firefox)**, and select **Set up
Firefox add-on**. Copy the manifest path, load it in Firefox, then select
**Test connection**. A successful test offers a link that opens Chat with
Claude.ai selected. The chat provider picker links back to the same setup.

Use Firefox as your default browser and sign in to Claude.ai there. Firefox
removes temporary add-ons when it restarts. Reload the add-on before your next
chat. This is the same local, text-only browser provider used by native engines.

Chat now keeps readable provider names after API key changes and shows clearer
empty-model and Firefox connection messages.
