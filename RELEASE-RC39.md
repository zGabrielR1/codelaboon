# RC39 connects model routing, task controls, and engine maintenance

- Choose **Free (Auto)** in Web Chat to route across available free models. Each reply shows the provider and model that answered.
- Free Auto reuses health and performance observations across candidates, includes non-streaming latency in its rankings, and tries another provider promptly after a rate limit.
- Pause or stop a continuous task to suspend its linked agent's desktop access at the next tool call. The Desktop and Tasks pages show linked agents and provide individual pause and resume controls.
- Open **Engine maintenance** in Tasks to see OpenCode and OMP runtime health, the latest maintenance result, and CLI repair commands.

Run `codelaboon update` from a terminal to update an existing installation after the release is published. Restart Codelaboon and any running task workers after updating so new desktop sessions use the linked controls.
