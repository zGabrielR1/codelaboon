# RC37 simplifies the task workspace

The Tasks page uses shorter labels and shows worker state separately from the
task count. App verification reports the current step and its result in plain
language. Task status, approvals, logs, and desktop controls remain available.

```sh
python -m pip install 'codelaboon[native-desktop] @ https://github.com/zGabrielR1/codelaboon/releases/download/v1.0.0-rc.37/codelaboon-1.0.0rc37-py3-none-any.whl'
```

See [the Linux app verification guide](README.md#build-launch-and-verify-a-linux-app)
for the workflow and desktop requirements.
